# v03の構成

- ユーザー指定により、v03は単一leaf bundleではなく、モデリング画面等を持つbranch bundleとする。公開するまで入口と子ページを下書きにする。
- foliage-modelerは単木の制作画面。生成処理leaf-library.tsはDOM・GPUに依存せず、葉のクラスと配置を返す。将来の配置・描画からも利用できる境界を保つ。
- 枝葉の塊を木へ取り付ける部品として制作する。葉だけの旧生成・比較は廃止。小32tri＝枝2区間12tri＋葉10枚20tri、中64tri＝枝4区間24tri＋葉20枚40tri、大128tri＝枝4区間24tri＋葉52枚104tri。
- 扇状・丸い塊・垂れ枝・松風の4バリエーションをクラス内の共通uint16 IB＋Storage VBで描く。葉は4頂点2tri。枝・葉の元データと所属枝ID・生成条件を保持する。
- 枝葉部品の取り付け原点はローカル(0,0,0)、+Yが成長方向。樹木は主幹＋主要枝の分岐骨格上に枝葉を配置する。樹形は共通パラメータのプリセットとして扱い、生成処理を樹形名で分岐させない。どのプリセットも主要枝0〜3本に編集できる。骨格枝は親IDと親線分への接続位置を持つ。主幹・主要枝はwood-mesh.tsで展開済み頂点の管メッシュを生成し、枝数/LODが同じ形状でIBを共有する。モデリング用のline-listは任意表示でForward後・深度テストあり・深度書込なし。Modelerでは幹3段・枝葉4段LODを手動選択し、枝葉の横並び比較も用意する。規模クラスとLODは独立。leaf-lod.tsでLOD0から代表葉を選び、位置・寸法を補正する。
- 配置Storageは48byte（位置/スケール、Quaternion、uint32 ID＋予約領域）。ZOnly/Forwardで回転を共有し、容量超過時のみ配置バッファを拡張。中心線ON/OFFで配置を変えない。
- MassInstance描画と呼ぶ。初期実装はCPU配置、GPUカリング・Indirect・自動LOD・風・保存形式は未実装。
- プレビューはZPrePass、Forward、HDRのトーンマッピングを分離する。影は初版では未実装。シーン用レンダラの代替とは扱わない。
- 静止時の連続描画はしない。モデル再生成とカメラ変更を分離し、GPU資源は再生成・終了時に破棄する。
- コメントは日本語。公開済みの版から実行資源を参照しない。

- tree-preview.tsは1〜4形状の単木アセットを再利用して1〜100本配置する。木の幹頂点は複製せず形状IDで参照し、同じクラス/LODは1 Draw/パス。枝葉配置は初版ではCPUでワールド展開する。異なる主要枝数クラスの同時表示とGPUソケット参照は未実装。接合部は交差管であり、溶接済みの一体メッシュと説明しない。


## rendererのGPU植生

- renderer/はv02の製品ソースを独立版として継承する。v02を編集せず、実行時に過去版を参照しない。モデル生成だけは同じv03のfoliage-modeler/のDOM非依存処理を共有する。
- ランタイムの配置要求選択・候補生成・地形への接地・カリング・LOD・Indirect引数はGPUで処理する。CPUによる木/葉配置配列の再展開は禁止。初期化時のモデル生成と転送はCPUでよい。
- 標高更新→チャンク生成→ビュー別カリング→ZPrePass→CSM→Forward→PostProcessの順。ZOnly/Forwardで位置と可視リストを共有し、discard/clip/PS深度出力を使わない。
- 64m・13×13チャンク、64候補/チャンクの固定容量。ヘッダーの世界座標と世代タグで再利用を検証し、最細Height Clipmapの有効範囲内だけを参照する。グローバルAtomicはWorkgroupで圧縮後の領域予約に限定する。
- 主幹3LODと枝葉4LODは投影サイズから独立に選択しMainはヒステリシス付き。枝葉は木単位で選択し、同じ規模クラス・同じLODの3形状でIBを共有する。各ビューは幹3領域・枝葉4領域へGPU圧縮し、最大7 Indirect Draw/ビュー/パス。枝葉の固定LOD・LOD色分けを用意する。風/遮蔽カリングは未実装。描画256m/影384mの制限を明示する。
- 非同期読み戻しは進捗表示と静止時の更新終了に使い、可視数やDraw引数をCPUで決めない。tests/foliage-streaming.htmlは実WGSLの生成・キャッシュ保持・圧縮をGPU検証する。

- rendererの樹木は円錐/卵/しだれの3種。幹は同じ主要枝数3のトポロジ。CSM既定256m、分割は対数90%/線形10%。深度バイアスはm単位で各段の投影深度スケールへ換算し、法線バイアスもm単位。
